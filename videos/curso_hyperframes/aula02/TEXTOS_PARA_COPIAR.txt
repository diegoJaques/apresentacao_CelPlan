===== DESCRIÇÃO =====
Aula 2 do curso de HyperFrames: um vídeo feito do zero, com prints reais de cada passo.

O passo a passo:
- criar o projeto a partir de um modelo pronto;
- abrir o Studio (prévia e linha do tempo);
- trocar o texto do vídeo, direto no código ou pedindo para o agente;
- gerar o MP4.

Comandos da aula:
npx hyperframes init meu-primeiro-video --example kinetic-type
cd meu-primeiro-video
npx hyperframes preview
npx hyperframes render --output meu-video.mp4

O texto da 1ª cena fica em compositions/main-graphics.html.

Pedido de exemplo para o agente:
Troque o título final para "Meu primeiro vídeo"

Capítulos:
0:00 Criar o projeto (init)
0:25 Abrir o Studio (preview)
0:34 Conhecendo o Studio
0:46 Mudar o texto no Code
1:11 Pedir mudanças para o agente
1:20 Gerar o MP4 (render)
1:33 O resultado
1:42 Recapitulando
