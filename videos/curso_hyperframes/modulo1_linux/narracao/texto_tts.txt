Nesta aula você prepara um computador com Linux do zero. Tudo o que aparece aqui é real: este é um Ubuntu de verdade, e eu vou digitar cada comando no terminal. Primeiro, atualize a lista de programas. Digite sudo apt update e aperte Enter. O sudo pede permissão de administrador, então ele pode pedir a sua senha. Agora instale o FFmpeg, o programa que o HyperFrames usa para gerar o arquivo de vídeo. Ele baixa tudo sozinho, e eu acelerei essa parte. Para conferir, digite ffmpeg traço version. Se aparecer a versão, deu certo. Agora o Node, o motor que roda o HyperFrames. No Linux, o jeito recomendado é pelo nvm. Copie este comando da página do nvm e cole no terminal. Depois, recarregue o terminal com source til barra ponto bashrc. Agora instale o Node vinte e dois: nvm install 22. Ele baixa e configura tudo em poucos segundos. Confira com node traço v e npm traço v. O Node precisa começar com 22 ou mais. Hora de testar o HyperFrames. Digite ene pê xis, traço traço yes, hyperframes arroba latest, traço traço version. Apareceu um número? Então ele está funcionando. Por último, o Claude Code, a inteligência artificial que monta os vídeos com você. É um comando só, tirado do site oficial. No final, o instalador avisa que falta um ajuste e já mostra o comando. É só copiar e rodar. Confira com claude traço traço version. Pronto: o seu Linux tem tudo o que o curso precisa. Recapitulando: o FFmpeg pelo apt, o Node pelo nvm, e o Claude Code pelo instalador oficial. Na próxima aula, a gente abre o Claude Code e faz o login.
